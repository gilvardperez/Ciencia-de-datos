# Ciencia de Datos

Bienvenido al repositorio **Ciencia-de-datos**, un espacio de aprendizaje y práctica de ciencia de datos con Python. Aquí encontrarás cuadernos (notebooks) que explican paso a paso conceptos fundamentales de estadística, análisis de datos y visualización, pensados para quien está empezando o quiere reforzar sus bases.

Cada notebook es autocontenido: incluye la explicación teórica, el código y ejemplos prácticos con datos reales, para que puedas seguirlo y ejecutarlo en tu propio entorno.

---

## Contenido

### 1. Análisis de componentes principales
Introducción al **PCA (Análisis de Componentes Principales)**, una técnica de reducción de dimensionalidad. Aprenderás a identificar las direcciones de mayor varianza en los datos, reducir el número de variables sin perder información relevante y visualizar los resultados.

### 2. Bootstrap
Técnica de **remuestreo estadístico** para estimar la incertidumbre de una métrica (media, mediana, etc.) cuando no se conoce la distribución de los datos. Incluye ejemplos de intervalos de confianza y comparación de estimadores.

### 3. Estandarización
Concepto de **estandarización (z-score)**: transformar variables para que tengan media 0 y desviación estándar 1. Se explica cuándo es necesaria (por ejemplo, antes de aplicar PCA o modelos sensibles a la escala) y cómo se aplica con Python.

### 4. Visualizando outliers (valores atípicos)
Métodos para **detectar y visualizar valores atípicos** en los datos, usando gráficos como boxplots y diagramas de dispersión, y criterios estadísticos para identificarlos.
